# Qwen3-4B backbone replication

Only activation backbone and its required tokenizer/native template and matched relative layer are changed from the Llama-3.2-1B experiment. Qwen3-4B-Instruct-2507 is pinned in backbone.json. BF16, SDPA, eval mode, use_cache=False; block index 24 (25/36), nearest relative depth to original block index 10 (11/16). All activations are freshly extracted; all probes freshly fit.

Exact original ordered rows, labels, groups, input hashes and train/validation/test memberships are retained from ten-dataset-full-20261002 metadata. Balanced training and natural validation/test populations are unchanged. Source metadata, revisions and verification records are archived on the instance. Native template tokenization changes lengths: retain every frozen example, never truncate or exclude due to the old tokenizer's 4096 limit. Use batches at most 4 with padded-token budget 8192; any longer single row runs alone.

Content positions are located by sentinel substitution and verified by exact rendered-text reconstruction. Pool eligible non-special content tokens; exclude padding and chat markers. User, assistant-response and all-message tasks retain previous target roles. Fresh pooled activations for every split and all-token activations for test only. StandardScaler fits training only; class-weighted L2 logistic regression C=.01 except HighStakes .001, lbfgs max_iter=2000 tol=1e-6. Threshold maximises validation F1 with highest-threshold tie break. No PCA, new hyperparameter search or test tuning.

Select up to 500 new probe-positive test cases per dataset using the same SHA256 ranking: seed 20261002 + NUL + dataset + NUL + sample_id. Selection uses no test label or judge outcome; record IDs and selection probabilities in SAMPLE_FROZEN.json. Same ordered selected rows across all nine judge conditions. New explanations use Qwen activations: highest mean-logit sentence and exact cosine nearest neighbour from balanced training-standardized pooled representations. Probe predictions on references use newly validation-tuned thresholds.

Unchanged Qwen/Gemma/Llama judge revisions, rubrics, prompts and greedy one-token constrained decoding settings, no generation of reasoning. Fresh judgments for this replication; reused.jsonl empty. Preserve raw judgments, exact rendered prompts/tokens, package/driver versions and source checksums. No silent retries or replacement outputs. supervisor stops and records error if any stage fails. Use PIPELINE_COMPLETED only for whole-study completion; COMPLETED means probe stage complete.

Evaluation is identical to prior sampled run: exact full-test probe metrics, observed sampled-flag LLM metrics, gold-class post-stratified estimated full-test cascade metrics and 2000 paired within-class row-bootstrap intervals. Fixed unflagged outcomes. Intervals conditional on fixed probes/test pool, approximate, no group correlation or backend variability correction; census strata fixed. Few negatives can make intervals unreliable. Original FAVA imbalance, HaluEval length shortcuts and exploratory test reuse remain. Changing model family and size simultaneously does not identify their individual causal contributions. Fixed data/configuration do not guarantee bit-identical fresh vLLM outputs.
