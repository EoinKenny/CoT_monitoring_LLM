# Gemma 4 31B backbone replication

Official google/gemma-4-31B-it, pinned in backbone.json. BF16 checkpoint tensors; no quantisation. Extract decoder block index 40 (41/60), retaining the original model configuration and exact first 41 blocks. Final normalization, later decoder blocks, language head and vision tower are unnecessary for the requested residual activation. CPU embedding lookup saves GPU memory; its scaled BF16 output is transferred to the GPU. A miniature full-stack/prefix equivalence check, real-weight coverage checks, content-mask reconstruction, longest-input checks and throughput preflight gate the full extraction.

Exact frozen ordered split memberships from ten-dataset-full-20261002. No truncation or resampling of train/validation/test data. Mean eligible content-token activations, excluding padding and template markers; task-specific roles unchanged. Train StandardScaler only on training, class-weighted logistic regression C=.01 except HighStakes .001, validation-F1 threshold with highest-threshold tie break. No PCA or test tuning. Save pooled activations for every split and token activations for test; preserve all outputs.

Positive-only cascade; up to 500 flags per dataset selected by the existing SHA256 rule (seed 20261002). Same flags across all five judges and three conditions within this backbone. New Gemma saliency and exact training-only nearest neighbours. Original Qwen, Gemma, Llama, GLM and OLMo judge checkpoint paths, prompt semantics and quantisation settings retained. Greedy constrained one-token binary decisions; no generated reasoning. No automatic regeneration/retry of failed experiments.

supervise.py runs download wait, preparation, smoke benchmark, extraction/probes, audits, explanations, all 15 judge conditions, evaluation and compare.py. It survives SSH disconnection and stops on an error with a traceback. run/status and pipeline status distinguish progress; PIPELINE_COMPLETED is written only after final verification and comparison reports.

ALL_BACKBONES_REPORT.md and ALL_RESULTS.csv compare three backbones, five judges and ten datasets. Full-test probe metrics are exact; cascade metrics are estimates from the sampled flags with class post-stratification and conditional paired bootstrap intervals. Flagged case sets differ across backbones. Do not treat cross-backbone differences as paired identical-case results, or attribute differences separately to family/size/layer. FAVA class imbalance, HaluEval shortcuts and exploratory test reuse remain. Exact data and configuration reproducibility does not imply bit-identical regenerated model outputs.

The runtime uses the existing vLLM Python environment and appends the existing CPU-analysis package directory via sitecustomize.py. No installed environments are changed. Source checksums and package/GPU metadata are recorded. The original stalled download log is preserved; the replacement downloader uses IPv4 to avoid unreachable IPv6 routes.
